# RGROsobistofood

Клієнтська частина web-додатка служби доставки страв. Проєкт розроблено як функціональний прототип інтерфейсу для оформлення онлайн-замовлень.

## Архітектура та логіка роботи

* **Тип додатка:** Багатосторінковий додаток (MPA) зі статичною маршрутизацією між категоріями.
* **Управління станом:** Логіка віртуального кошика реалізована виключно на стороні клієнта. Дані про обрані товари, їхню кількість та розрахунок загальної вартості замовлення обробляються динамічно в пам'яті браузера.
* **Структуризація контенту:** Асортимент розподілено на ізольовані директорії за категоріями (піца, роли, напої). Дані про страви (назви, описи, ціни) імплементовані безпосередньо в HTML-розмітку відповідних сторінок.
* **Побудова інтерфейсу:** Макет базується на сітці Bootstrap для забезпечення перебудови блоків на різних роздільних здатностях екрана. Інтерактивні елементи (слайдер, висувне мобільне меню) керуються користувацькими скриптами шляхом маніпуляцій DOM через бібліотеку jQuery.

## Розгортання та запуск

Проєкт складається зі статичних ассетів і не вимагає збірки, встановлення залежностей або налаштування локального сервера. Робота в середовищі розробки чи тестування здійснюється шляхом відкриття головного файлу безпосередньо у веб-браузері.
